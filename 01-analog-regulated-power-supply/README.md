# Adjustable Regulated DC Power Supply (3V - 12V)

An analog electronics project focused on designing and fabricating a linear regulated DC power supply capable of converting 220V AC input into an adjustable 3V - 12V DC output.

## 📌 Features
- **Input:** 220V AC (Grid Line)
- **Output:** Adjustable DC Voltage (3V, 5V, 6V, 9V, 12V DC)
- **Real-time Monitoring:** Integrated Digital Voltmeter Panel
- **Simulation Validated:** Tested on Falstad and Tinkercad before hardware assembly

## 🛠️ Hardware Components
- Transformer 2A CT (Step-Down)
- Rectifier: 4x 1N4007 Diodes (Full-Bridge)
- Filtering: 2.2mF Electrolytic Capacitor
- Voltage Regulator: IC LM317
- Adjustment: 5kΩ Potentiometer
- Enclosure & Monitoring: Custom Project Box + Panel Meter
