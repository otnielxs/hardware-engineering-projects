# BAYMAX LITE 2.0: Interactive Digital Health Monitoring System

A digital electronics project focused on designing and building an interactive health monitoring system capable of measuring body temperature and pulse rate (BPM), providing real-time visual display and voice responses[cite: 2, 3].

📌 Features

* Input: Infrared Non-Contact Temperature & Pulse Photoplethysmography (PPG)[cite: 2, 3]
* Output: LCD Display 16x2 I2C & Interactive Voice Response (DFPlayer Mini MP3)[cite: 3]
* Real-time Monitoring: Instant health status feedback based on biometric thresholds[cite: 2, 3]
* Automated Classification: Dual-parameter logic evaluating normal, high, and low physiological conditions[cite: 3]

🛠 Hardware Components

* Microcontroller: Arduino Uno (ATmega328P)[cite: 2, 3]
* Temperature Sensor: MLX90614 Non-Contact IR Sensor[cite: 2, 3]
* Pulse Sensor: Pulse Sensor Amped (Photoplethysmograph)[cite: 3]
* Audio System: DFPlayer Mini MP3 Module + 8Ω Mini Speaker + MicroSD Card[cite: 3]
* Display Interface: LCD 16x2 Panel with I2C Adapter[cite: 3]
* Prototyping & Enclosure: Breadboard, Jumper Wires & Custom Enclosure Box[cite: 3]
