# BAYMAX LITE 2.0: Interactive Digital Health Monitoring System

A digital electronics project focused on designing and building an interactive health monitoring system capable of measuring body temperature and pulse rate (BPM), providing real-time visual display and voice responses.

📌 Features

* Input: Infrared Non-Contact Temperature & Pulse Photoplethysmography (PPG)
* Output: LCD Display 16x2 I2C & Interactive Voice Response (DFPlayer Mini MP3)
* Real-time Monitoring: Instant health status feedback based on biometric thresholds
* Automated Classification: Dual-parameter logic evaluating normal, high, and low physiological conditions

🛠 Hardware Components

* Microcontroller: Arduino Uno (ATmega328P)
* Temperature Sensor: MLX90614 Non-Contact IR Sensor
* Pulse Sensor: Pulse Sensor Amped (Photoplethysmograph)
* Audio System: DFPlayer Mini MP3 Module + 8Ω Mini Speaker + MicroSD Card
* Display Interface: LCD 16x2 Panel with I2C Adapter
* Prototyping & Enclosure: Breadboard, Jumper Wires & Custom Enclosure Box
